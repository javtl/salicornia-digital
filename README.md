# 🌿 Salicornia Digital

Aplicación completa de gestión de cultivo de salicornia (30 días, 7 devs).

## 📁 Estructura

```
salicornia-digital/
├── salicornia-api/       # Backend (Node.js + Express)
├── salicornia-web/       # Frontend (React)
└── docs/                 # Documentación del proyecto
```

## 🚀 Inicio rápido

### Backend
```bash
cd salicornia-api
npm install
cp .env.example .env
# Editar .env con tus datos
npm run dev
```

### Frontend
```bash
cd salicornia-web
npm install
cp .env.example .env
npm run dev
```
